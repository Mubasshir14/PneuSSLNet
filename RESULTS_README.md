## 3. Publication Figures Regeneration Map

All figures are automatically generated in publication-grade vector PDF and 300-DPI raster PNG formats:

1. **Figure 1 — Revised PneuSSLNet Architecture Diagram:** Depicts unlabeled SSL pretraining (SimCLR, MoCo, BYOL, DINO), 2-stage downstream adaptation, locked internal test, and external RSNA evaluation.

8. **Figure 8 — Calibration & Reliability (`figures/main/figure8_calibration_curve.png`):** Calibration curves and reliability diagrams showing expected calibration error (ECE).

## 4. Integrity Verification & Reproducibility Check

To verify reproducibility of the entire workspace after completing your Kaggle run:
```bash
python -c "
import json
with open('configs/experiment_config.json') as f:
    cfg = json.load(f)
print('Verified Run ID:', cfg['RUN_ID'])
print('Split Seed:', cfg['SPLIT_SEED'])
print('Random Seeds:', cfg['SEEDS'])
"
```
Check that `registry/checkpoint_index.csv` records all models as `validated=True`.
